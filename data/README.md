# RetentionLab Data Directory

This directory stores the deterministic synthetic dataset and analytical artifacts produced by the RetentionLab pipeline.

## Directory Structure
- `raw/`: Raw CSV extractions generated by `SyntheticDataGenerator`:
  - `customers.csv` (5,000 records)
  - `transactions.csv` (104,990 records; exceeds >97k requirement)
  - `products.csv` (10 records)
  - `customer_activity.csv` (115,813 records)
  - `support_tickets.csv` (7,115 records)
  - `campaign_interactions.csv` (32,655 records)
  - `customer_snapshots.csv` (5,000 records)
- `processed/`:
  - `customer_features_44.csv`: 4,850 eligible accounts x 44 documented behavioral features.
  - `churn_labels.csv`: Leakage-free 60-day future horizon churn target (`is_churn`).
  - `customer_prioritization.csv`: Master customer-level scoring table with churn probabilities, risk bands, exposure values, and recommended actions.
- `exports/`:
  - `RetentionLab_Retention_Action_Workbook.xlsx`: Multi-sheet professional Excel action report with conditional formatting.
- `retentionlab.db`: Relational SQLite database loaded and indexed for fast SQL analytics.

## Reproducibility
All datasets are deterministically regenerated with:
```bash
python scripts/generate_data.py
```
Default random seed: `42`.
Snapshot date: `2026-04-01`.
Prediction horizon: 60 days (`2026-04-01` to `2026-05-31`).
Historical observation window: Trailing 180 days prior to snapshot date.
